# AI in Coaching — Coaching AI Decision Workbench

A practical, sourced session on choosing and using AI behind the coach, not in the chair.

**View it:** https://loxlyatkinson.github.io/ai-in-coaching/

A single self-contained HTML file — fonts, images and artwork are all inlined, so it makes
zero network requests and works offline. Open `index.html` directly if you prefer.

## Getting around

| Key | Does |
|---|---|
| `→` `Space` `Enter` `PageDown` | Forward |
| `←` `Backspace` `PageUp` | Back |
| `G` | Overview grid — `Esc` closes it |
| `Home` / `End` | First / last screen |
| `Ctrl+P` | Print / save the 37-page archive |

You can also click the right side of the screen to advance, or the left edge to go back.

29 content slides across 39 screens. Best viewed at 1440×900 or wider.

## About this build

This is the shared web edition. It is generated from the same three sources as the
presenter's copy, with one difference: **the presenter view and the speaker notes are not
included.** The spoken script is stripped at build time rather than merely hidden, so it is
absent from this file rather than sitting in the page source.
